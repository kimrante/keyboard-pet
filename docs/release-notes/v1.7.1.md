## Keyboard Pet v1.7.1

성능·메모리·경량화 릴리스입니다. 성능과 메모리 누수 관점의 코드 리뷰를 3회 진행해 반영했습니다.

### 메모리
- 설정 창을 열고 닫을 때마다 설정 화면 데이터(프레임 이미지 포함)가 앱 종료까지 남던 누수를 고쳤습니다.
- 이미지 세트가 여럿이어도 **사용 중인 세트만 디코딩**합니다. 나머지는 폴더만 훑어 상태를 보여 주고, 세트를 바꿀 때 그때 읽습니다.
- 디코딩한 프레임이 파일 원본 바이트까지 붙잡던 것을 픽셀만 남기도록 바꿨습니다.
- 설정 창의 규칙·효과·세트 목록이 전체 해상도 프레임 대신 작은 썸네일(64px)을 쓰고, 썸네일은 한 번만 만들어 공유합니다. 세트 카드가 파일을 다시 디코딩하지 않습니다.

### CPU·유휴 상태
- 주기적으로 깨어나던 것을 없앴습니다: 2초마다 돌던 '항상 위' 재적용 타이머는 전경 창이 바뀔 때만 동작하고, 타이핑 속도 연동 모드는 입력이 없으면 타이머를 멈춥니다.
- 펫 창을 숨기거나(Alt+F4) 세션을 잠그면 애니메이션과 효과 계산을 멈춥니다. 트레이 메뉴에 **펫 보이기**가 생겼습니다.
- 키 입력 중 아무도 쓰지 않던 키 업 이벤트를 UI 스레드로 넘기지 않고, 키 다운 전달에서 리플렉션 호출을 없앴습니다.
- 효과가 움직이는 동안은 이미지를 한 번 캐시해 두고 변형만 해서 프레임당 렌더 비용을 줄였습니다.
- 슬라이더를 움직일 때마다 설정 창 전체를 다시 동기화하던 것을 바뀐 부분만 하도록 바꿨습니다. 501개 항목 콤보박스는 가상화했습니다.

### 시작·저장·기타
- 펫이 먼저 보이고, 트레이 아이콘·자동 실행 등록·안내 메시지는 그 뒤에 처리합니다.
- 설정 저장을 백그라운드 스레드에서 수행해 UI가 디스크를 기다리지 않습니다(저장 실패는 다시 시도).
- 런타임 옵션을 트레이 앱에 맞게 조정했습니다(동시 GC·PGO 계측·EventSource 끄기 등).

### 고친 버그
- **타이핑 속도 연동 모드에서 빠르게 칠수록 펫이 멈추던 문제**: 키 입력마다 타이머가 되감겨 틱이 오지 않던 것을 고쳤습니다.
- 규칙만 고쳐도 세트 효과가 처음부터 다시 시작되던 문제, 세트 이름에 공백을 붙이면 카드가 다시 만들어지던 문제를 고쳤습니다.

### 호환성
- 설정 파일 형식은 v1.7.0과 같습니다.
