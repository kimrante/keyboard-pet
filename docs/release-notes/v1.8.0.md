## Keyboard Pet v1.8.0

키보드뿐 아니라 **마우스 클릭과 펜 입력**에도 펫이 반응하도록 옵션을 추가했습니다.

### 새 기능: 마우스 클릭·펜 입력
설정 창 **일반 → 입력**에서 켤 수 있습니다(기본은 꺼짐).
- **마우스 클릭도 입력으로 계산 (터치 탭 포함)**: 클릭할 때마다 키를 한 번 누른 것처럼 타수와 애니메이션에 반영됩니다.
- **펜 입력도 입력으로 계산**: 펜이 화면(태블릿)에 닿는 순간 한 번 세고, **대고 있는 동안에는 설정한 간격마다 한 번씩 더 세서 프레임이 계속 넘어갑니다.**
  간격은 **누르고 있을 때 간격** 슬라이더로 조절합니다(30~1000ms, 기본 150ms). 타수 기반·타이핑 속도 연동 모드에서도 펜을 가만히 누르고 있으면 애니메이션이 이어집니다.
- 펜은 Windows Ink 펜의 팁 접촉 신호로 인식해, Windows의 "길게 눌러 오른쪽 클릭" 판정과 관계없이 누르고 있는 동안 바로 반응합니다.
  이 신호를 받을 수 없는 장치에서는 펜이 만든 마우스 메시지로 대신합니다.
- 클릭과 펜 입력은 타수와 애니메이션에만 반영되며, 키 매핑 규칙에는 쓰이지 않습니다.
- 두 옵션이 모두 꺼져 있으면 마우스 입력 감지를 아예 설치하지 않습니다. 켜면 별도 스레드에서 동작하므로 마우스 커서 움직임에 영향을 주지 않습니다.

### 개인정보
- 버튼을 누르고 뗀 사실과 펜이 닿았는지만 받습니다. 클릭한 위치나 창은 읽지 않으며, 기록·저장·전송하지 않습니다.

### 호환성
- 설정 파일 형식은 v1.7과 같습니다. 새 항목(`countMouseClicks`, `countPenInput`, `penRepeatMs`)이 없으면 기본값(꺼짐, 150ms)을 씁니다.
- 실행 옵션 `--no-hook`은 이제 키보드와 마우스 입력 감지를 모두 생략합니다.
