## Keyboard Pet v1.7.2

안정성·성능 릴리스입니다. 코드 리뷰 2회와 성능 최적화 1회를 반영했습니다.

### 고친 버그
- **설정 변경이 저장되지 않을 수 있던 문제**: 저장이 끝나는 순간에 바꾼 설정이 파일에 쓰이지 않고, 종료할 때도 다시 저장되지 않아 마지막 변경이 사라질 수 있었습니다.
- **드래그앤드롭으로 이미지를 가져올 때 일부 파일이 실패하면 전체가 어긋나던 문제**: 새 세트 카드가 설정에 저장되지 않거나, 이미 복사된 파일이 카드에 나타나지 않았습니다. 이제 실패한 파일만 건너뛰고 몇 개가 실패했는지 알려 줍니다.
- 우클릭·트레이 메뉴에서 **이미 선택된 애니메이션 모드를 다시 누르면 체크 표시가 사라지던 문제**를 고쳤습니다.
- `--data-dir` 옵션을 쓰면 "새 세트" 폴더도 그 위치 아래에 만듭니다(이전에는 항상 실제 사용자 폴더를 썼습니다).
- 오류 로그(crash.log)가 1MB를 넘으면 crash.old.log로 넘기고 새로 써서, 한없이 커지지 않습니다.

### 성능
- 설정 창용 썸네일을 **설정 창이 열려 있을 때만** 만듭니다. 펫만 쓰는 동안에는 시작하거나 세트를 다시 불러올 때 만들지 않습니다.
- 설정 창을 열 때 세트 카드 썸네일을 같은 파일에서 여러 번 다시 읽던 것을 한 번만 읽도록 바꿨습니다.

### 호환성
- 설정 파일 형식은 v1.7.0과 같습니다.
