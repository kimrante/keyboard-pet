## Keyboard Pet v1.7.0

### 새 기능: 움직임 효과
- **8가지 효과**: 위아래 흔들기, 좌우 흔들기, 작아지기, 커지기, 튀어오르기, 기울이기, 말랑하게 찌그러지기, 깜빡이기. 이미지 파일을 바꾸지 않고 펫 창에서 이미지를 움직입니다.
- **강도·속도 조절**: 효과마다 강도(0~100%)와 속도(한 번 움직이는 시간)를 따로 조절합니다.
- **복합 설정**: 효과를 여러 개 추가하면 함께 적용됩니다(예: 위아래 흔들기 + 기울이기).
- **적용 프레임 선택**: 효과마다 모든 프레임에 적용할지, 특정 프레임(키 전용 프레임 포함)이 보일 때만 적용할지 고릅니다.
- **키 매핑 효과**: 키 매핑 규칙에 효과를 추가하면 그 키를 누른 순간부터 유지 시간 동안 재생됩니다. 세트 효과와 합성됩니다.
- 효과는 이미지 세트마다 따로 저장되며(설정 → 효과 탭), 효과가 있으면 펫 창 둘레에 클릭이 통과하는 투명 여백이 생겨 움직임이 잘리지 않습니다.

### 기타
- `--screenshot <폴더>` 무인 실행 모드와 `--data-dir <폴더>` 옵션(설정 폴더 지정) 추가. PR마다 CI에서 앱을 실행해 스크린샷을 남깁니다.

### 호환성
- v1.6.0 설정 파일을 그대로 읽습니다. 효과가 없는 세트는 이전과 똑같이 표시됩니다.
