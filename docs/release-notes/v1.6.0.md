## Keyboard Pet v1.6.0

### 변경 사항
- **설정이 이미지 세트를 따라갑니다**: 일반 탭의 기본 기능(항상 위, 배율, 불투명도, 클릭 통과, 타수 표시, 자동 실행, 키 반복 반영)을 제외한 애니메이션 방식과 키 매핑은 모두 이미지 세트마다 따로 저장됩니다. 사용할 세트를 바꾸면 그 세트의 설정으로 함께 전환되고, 세트 이름을 바꾸면 설정도 따라가며, 세트를 삭제하면 설정도 함께 지워집니다. 새 세트는 기본 애니메이션 설정과 빈 키 매핑으로 시작합니다.
- **키 매핑이 세트 안에서 동작합니다**: 규칙은 더 이상 다른 세트로 전환하지 않고, 사용 중인 세트의 **프레임 한 장** 또는 **애니메이션 재생**을 고릅니다. 규칙 행의 세트 선택 칸이 없어졌습니다.
- **애니메이션·키 매핑 탭 상단에서 사용할 세트를 바로 고를 수 있습니다.** 고른 세트에 표시할 프레임이 없으면(빈 세트 등) 예시 세트가 대신 보인다는 안내가 나옵니다.
- **내장 샘플 정리**: idle·typing 샘플을 삭제하고 jump 이미지만 남겨 **`예시`** 세트로 이름을 바꿨습니다. 예시 세트에는 `Enter → 2번 프레임 0.8초` 샘플 규칙이 들어 있습니다.
- 키 전용 프레임을 보여 주던 규칙이 끝나면 루프 애니메이션으로 바로 돌아옵니다.
- 세트 이름이 비어 있거나 다른 세트와 겹치면 고칠 때까지 세트 변경을 저장하지 않고 안내합니다.

### 호환성 (이전 설정 파일 자동 변환)
- v1.5.0 이하의 설정 파일은 처음 실행할 때 자동으로 변환됩니다(원본은 `settings.json.bak`으로 남습니다).
- 공통 애니메이션 설정은 각 세트로 복사되고, 규칙은 자기 세트를 가리키던 것만 그 세트에 남습니다.
- **다른 세트로 전환하던 규칙과, 삭제된 idle·typing 샘플을 가리키던 규칙은 옮길 수 없어 제외됩니다.** jump를 가리키던 규칙은 `예시` 세트로 옮겨집니다.
- 기본 규칙을 그대로 쓰고 있었다면 `예시` 세트의 새 샘플 규칙으로 바뀝니다.
